## F. Things Rust does that the game does not
1. `RAGDOLL_FRICTION_SCALE 0.05` / `RAGDOLL_HOLD_DV 80` friction animation on ragdoll joints (`gm-server/src/lib.rs:23596-23633`): no counterpart in the binary (ragdoll joints have fixed per-model friction from the ragdoll data).
2. Jolt-side ballsocket damping ≈0.197/s (docs/spec/physics.md) added to match measured pendulum decay — the game gets it from vphysics' solver, not an explicit damper.
3. Trigger "flags == 0 → players can trigger" (mapio.rs:1766) — the game triggers nothing with no allow flags.
4. `PropData::modifier()` single-modifier precedence (G2) — game multiplies all applicable modifiers.
5. Death ragdoll: one per player, previous removed instantly (G12) — game uses an LRU of 8 with fade.
6. +use carry max speed 2500 u/s (G25) — SDK 1000.
7. `damage_prop` removes the prop in the hit tick with no gib/explosion (G4) and integer health steps.
8. Vehicle `DriveSpec` constants (wheel travel 60, tyre friction 1.0) not sourced from vehicle scripts (G30).
