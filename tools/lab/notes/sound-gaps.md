## Things the rewrite does that the game does not
- HRTF binaural rendering, elevation cues, Steam Audio volumetric occlusion / transmission / per-band air absorption, geometry-derived reverb (`gm-audio/src/engine.rs`, `acoustics.rs`, `scene.rs`). The game has 5-speaker panning, a trace-based ±2.7 dB occlusion (if any) and preset reverbs.
- Underwater low-pass that is its own filter (`engine.rs:156-158, 470`) instead of `dsp_water` preset 14 (lowpass + reverb).
- Random-position soundscape loops 100–500 u away (`soundscape.rs:11`) — the game uses 36 u.
- Scrape volume `slip/300` (`gm-server/src/lib.rs:1711-1714`) — a speed proxy; the game uses friction energy.
- Voice chat relayed by the server with Opus 48 kHz (`voice.rs`) — the game relies on Steam voice.
- Soft impacts under 320 u/s (`lib.rs:25235`) — the game picks by surface hardness.
