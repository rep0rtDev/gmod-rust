## C. Things Rust does that the game does not
1. W:258 crowbar `secondary_after 0.6667` – the game's crowbar alt-fire is a no-op and both timers are `now + 0.4`.
2. W:1010-1014 `RPG_ROCKET_DIED 1.6667` applied to *both* timers – the game only gates the primary via the reload sequence (the secondary is unused; harmless).
3. P:33-45 missile per-tick regression model (`ROCKET_TURN_KEEP/GAIN`, `FIRST_TURN`, `HOME_LIFT_*`) – the game uses the 0.1 s / 12.5 % blend; the fitted constants reproduce it only for a held aim.
4. P:70-72 grenade launch as fitted speed/offset (1189, 110, 33.69, 13.91) instead of the game's `eye + fwd*18 + right*8` and `(fwd + 0.1 up)*1200 + playerVel`.
5. W:248 crossbow `auto_reload (7 ticks, 1.8333)` is a measured stand-in for `mustReload && idleTimeElapsed` → correct timing but the reload will not restart if interrupted.
6. C:3790-3795 schedules `BoltElectrify` client-side from the reload event; the game plays it from the server charger state (`START_LOAD`) – equivalent audibly.
7. C:1151 tracer on every shot of every weapon – the game shows none for the .357/shotgun? (357: tracer freq 1 → yes; shotgun: `FireBullets` tracer freq 1 per pellet set? – shotgun pellets use tracer freq 2? treat as P2).
